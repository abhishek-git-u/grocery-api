# 📦 Grocery Store API  

🚀 **Grocery Store API** is a **Spring Boot** and **MySQL**-powered backend that provides **inventory management** and **order booking** functionalities for a grocery store. It is containerized using **Docker** and managed with **Docker Compose**.

---

## 📜 Features
- ✅ Add, update, delete, and retrieve grocery items  
- ✅ Manage customer orders  
- ✅ Uses **Spring Boot + JPA + MySQL**  
- ✅ Containerized with **Docker**  
- ✅ Supports **RESTful APIs**  

---

## 🛠️ Tech Stack
- **Backend:** Java 17, Spring Boot 3.1.2  
- **Database:** MySQL 8  
- **ORM:** Hibernate / JPA  
- **Build Tool:** Maven  
- **Containerization:** Docker, Docker Compose  

---

## 🚀 Setup Instructions  

### 1️⃣ Prerequisites  
Ensure you have installed:

- **Docker & Docker Compose**  
- **Maven**
